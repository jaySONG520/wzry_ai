# 示范录制说明（人类操作录制）

本说明文档介绍如何使用 `record_demo.py` 录制人类示范数据，以便进行行为克隆预训练。

## 1. 录制目的

示范数据包含：

- 每一帧游戏截图
- 对应的动作标签（动作索引）

该数据用于让模型先学会“基本操作”，降低纯强化学习的探索成本。

## 2. 运行前准备

1. 保证设备已连接（adb）。
2. 游戏已启动并进入对局（推荐）。
3. 在 Windows 环境运行（该脚本使用 Windows 键盘捕获）。

## 3. 运行命令

```bash
python record_demo.py --fps 8
```

常用参数：

- `--fps`：录制帧率（默认 8）
- `--max_seconds`：最大录制时长（秒，0 表示不限制）
- `--require_started`：仅在检测到对局开始时录制
- `--keymap`：按键映射 JSON 文件路径（默认 `record_demo_keymap.json`）

示例：

```bash
python record_demo.py --fps 10 --max_seconds 600 --require_started
```

## 4. 键位说明（默认）

默认按键会写入 `record_demo_keymap.json`（第一次运行自动生成），你可以按自己的习惯修改。

动作 → 按键（默认）：

- 移动：W/A/S/D
- 停止移动：无（默认不绑定）
- 普通攻击：鼠标右键（`mouse_right`）
- 技能 1/2/3：Q/E/R
- 技能 4（仅 4 技能英雄）：I
- 攻击小兵/塔：Z/X
- 回城/恢复：B/C
- 召唤师/装备技能：F/6
- 发起进攻/撤退/集合：H/J/K
- 升级技能：1/2/3/6（6 仅 4 技能英雄）
- 购买装备 1/2：4/5
- 开始录制/停止录制：= / -
- 退出录制：无（可使用 `Ctrl+C`）

你也可以复制一份映射文件并通过参数指定：

```bash
python record_demo.py --keymap my_keymap.json
```

## 5. 录制输出

录制数据将保存到：

```
data/demos/demo_YYYYMMDD_HHMMSS/
```

文件结构：

- `frames/`：截图序列（jpg）
- `actions.jsonl`：每帧动作标签
- `meta.json`：录制参数与映射说明

## 6. 关于大厅界面

建议尽量在对局内录制。大厅界面和战斗界面差异大，混在一起会影响训练效果。

如果你需要避免大厅界面，运行时加上：

```bash
python record_demo.py --require_started
```

该参数会用 `models/start.onnx` 判断是否进入对局。
